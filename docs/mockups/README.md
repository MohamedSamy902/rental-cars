# نماذج واجهات RPM

## للإرسال للعميل — PWA حقيقي (الإصدار الحالي)

المجلد: [`للعميل/`](للعميل/)

مبنية من تطبيق حي في [`../../ui-pwa`](../../ui-pwa) (موبايل + تابلت)، بالحقول من المواصفة ٣٫٣:

- ملخص سريع فوق القوائم
- فلاتر + بحث
- شيت إضافة بحقول كاملة
- صيانة: مخزون بالأقدم أولاً أو شراء (+ عهدة)

تشغيل المعاينة:

```bash
cd ui-pwa && npm install && npm run dev
# http://127.0.0.1:3847
```
