# فجوة مؤجّلة: قيود التأمين (محدَّث)

**الحالة:** التأمين النقدي ما زال مؤجّلاً؛ تحصيل دفعات العقود أصبح مُرحَّلاً.

## ما يعمل الآن
- إقفال العقد → قيد محاسبي عبر `AccountingService::postContractClose` مع توزيع الإيجار على شهور الخدمة (`rent_recog:{contractId}:{YYYY-MM}`) وإقفال الشهر يثبت استحقاق الإيجار قبل القفل.
- `POST /accounting/payments` لربط عقد → قيد متوازن نقدية/بنك/عهدة ↔ ذمم (`payment:{id}`) مع منع تجاوز المتبقي.
- المصروفات وترحيل مستحقات الملاك / الصرف لهم → قيود.
- المخالفات → متابعة بلا ترحيل (ن٫١١) — مقصود.

## ما لم يُرحَّل بعد (متعمد مؤقتاً)
- قبض / رد التأمين النقدي (`deposits`) يكتب صف `payments` فقط — بلا قيد على حساب 1300.
- مسير الرواتب / استلام المخزون — بلا قيود يومية كاملة.

## أثر على التقارير
دفتر الشهر وتقارير الإيجار تعتمد قيود `rent_recog` بتاريخ نهاية الشهر المعني. التأمينات ما زالت متابعة تشغيلية حتى يُغلق مسار 1300.

## المطلوب لاحقاً
قيود متوازنة للتأمين (نقدية/بنك ↔ التزام 1300) مع منع التكرار، ثم تحديث المعايير وRSD في نفس التغيير.
