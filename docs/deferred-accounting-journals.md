# فجوة مؤجّلة: قيود التأمين والدفعات

**الحالة:** مؤجّل بقرار صريح (موجة إصلاح التدقيق).

## ما يعمل الآن
- إقفال العقد → قيد محاسبي عبر `AccountingService::postContractClose` (مع منع التكرار بـ `source` فريد).
- المصروفات وترحيل مستحقات الملاك / الصرف لهم → قيود.
- المخالفات → متابعة بلا ترحيل (ن٫١١) — مقصود.

## ما لم يُرحَّل بعد (متعمد مؤقتاً)
- قبض / رد التأمين النقدي (`deposits`) يكتب صف `payments` فقط — بلا قيد على حساب 1300.
- `POST /accounting/payments` يكتب صف دفعة فقط — بلا قيد نقدية ↔ ذمم.
- مسير الرواتب / العهدة / استلام المخزون — بلا قيود يومية كاملة.

## أثر على التقارير
تقارير الحسابات ودفتر الشهر **لا تُقدَّم كصورة محاسبية نهائية** حتى تُغلق هذه الفجوة. تظهر الدفعات والتأمينات كمتابعة تشغيلية ومصدر قراءة جزئي.

## المطلوب لاحقاً
تصميم قيود متوازنة (نقدية/بنك ↔ التزام تأمين 1300، ونقدية ↔ ذمم للتحصيل) مع منع التكرار، ثم تحديث المعايير وRSD في نفس التغيير.
