# ملاحظات تنفيذ داخلية (ليست للعميل)

هذا الملف للفريق فقط. ملف العميل الرسمي: `docs/RSD.md`.  
**قبل أي شات جديد:** ابدأ حصراً بـ `docs/معايير-المشروع-الملزمة.md` (٢٫٠+ المرجع الواحد) ثم `AGENTS.md`.

## نموذج التسليم
- كل عميل يحصل على **نسخة منفصلة بالكامل** (تنصيب / بيئة مستقلة)، وليست منصة مشتركة متعددة المستأجرين في واجهة واحدة.
- لا يُذكر للعميل أي نية إعادة بيع أو استهداف عملاء لاحقين.
- لوحة المُدمج (ألوان، تعدد فروع، لوجو، اسم المركز، فيتشر فلاج) خاصة بمقدّم النظام — ليست شاشة موظفي المعرض.

## ستاك وتقنية (داخلي)
- Laravel خلفية — **Service فقط** لمنطق البيزنس (كنترولر رفيع)
- قاعدة البيانات: **MySQL** (InnoDB · utf8mb4) على cPanel
- واجهة SPA/PWA عربية RTL (مرجع حي: `ui-pwa`) — فورمات realtime بلا رفريش
- فاليديشن عربي + اختبارات تتجاوز الهابي باث
- أحداث نطاق للإشعارات والآثار الجانبية — تنفيذ داخلي
- قيد مزدوج، طوابير، وأرشفة ملفات حسب مواصفة العميل بالعربية

## عند الكتابة للعميل
- عربي فقط في `docs/RSD.md`
- أسماء حقول عربية
- بلا مصطلحات بنية تحتية أو خطط منتج داخلية أو مسارات ملفات الفريق
