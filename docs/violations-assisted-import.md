# تجربة جلب المخالفات (بدون سكرابينج)

**الحالة:** تجريبية · لا استدعاء آلي لبوابة PPO.

## لماذا لا يوجد سحب تلقائي؟
بوابة النيابة/المرور واجهة مواطن محمية بملكية المركبة (مصر الرقمية / OTP). لا يوجد API مرخّص لتطبيقات التأجير الخاصة. السكرابينج أو أتمتة الدخول مرفوض.

## ماذا نجرّب الآن؟
1. **مساعد يدوي:** من شاشة المخالفات → «استعلام + حفظ» → فتح الرابط الرسمي → نسخ الرقم/المبلغ/التاريخ → حفظ في RPM (مع مطابقة عقد بالحيازة).
2. **استيراد CSV:** ملف بأعمدة `لوحة,التاريخ,المبلغ,المكان,رقم_المخالفة,ملاحظات` (أو إنجليزي: `plate,occurred_at,amount,location,external_number,notes`).
3. **مزوّد رسمي (stub):** `OfficialPortalProvider` يعيد `source_unavailable` + رابط البوابة حتى يتوفر تعاقد مرخّص لاحقاً.

## مثال CSV
```csv
لوحة,التاريخ,المبلغ,المكان,رقم_المخالفة
ق ر ش 3320,2026-10-20 14:30,300,القاهرة,VIO-1001
```

## حدود
- بلا ترحيل محاسبي (ن٫١١).
- التكرار يُمنع عبر `(source, external_number)`.
- عند 0 أو أكثر من عقد حيازة محتمل → `needs_review=true`.
