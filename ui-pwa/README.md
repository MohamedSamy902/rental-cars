# RPM — معاينة واجهة PWA

مرجع حي لواجهة التشغيل العربية (RTL) وفق `docs/معايير-المشروع-الملزمة.md` و`docs/mockups/نظام-التصميم.md`.

```bash
npm install
npm run dev
```

افتح http://127.0.0.1:3847

## ما يشمله الأساس
- `AppShell` · تنقّل بلا رفريش (React Router)
- كومبوننتس موحّدة: حقول، شيت، توست، سكلتون، ملخص، فلاتر
- شاشات: لوحة اليوم · السيارات · الحجوزات · التقويم · الصيانة
- Zero-detour: إضافة عميل من داخل شيت الحجز
- حفظ وهمي يحدّث القائمة فوراً بلا `location.reload`
